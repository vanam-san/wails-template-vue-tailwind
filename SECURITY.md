# Security policy

The latest published template release receives security fixes. Generated applications manage their own updates and dependency versions. Check [the changelog](CHANGELOG.md) for release changes.

Report suspected vulnerabilities privately using the contact information on [Manav Mehta's GitHub profile](https://github.com/vanam-san). Include the template and Wails versions, the affected platform, reproduction details, and an impact summary. Keep credentials and personal data out of the report. Coordinate disclosure with the maintainer before sharing vulnerability details publicly.
