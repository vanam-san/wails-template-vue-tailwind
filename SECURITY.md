# Security policy

The latest published template release receives security fixes. Generated applications manage their own updates and dependency versions. Check [the changelog](CHANGELOG.md) for release changes.

Report suspected vulnerabilities privately to `<SECURITY_CONTACT_EMAIL_OR_URL>`. Include the template and Wails versions, the affected platform, reproduction details, and an impact summary. Keep credentials and personal data out of the report. Coordinate disclosure with the maintainers and avoid opening a public issue for an unpatched vulnerability.
